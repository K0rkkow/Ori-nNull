ORIØNNNULL / TECHNICAL OVERVIEW

01. PRÉSENTATION

OriønNull est un navigateur desktop conçu avec une priorité donnée à la confidentialité, à la simplicité de l'interface et à la réduction des données persistantes générées localement.

02. MOTEUR

L'application utilise Qt WebEngine pour afficher les pages Web. Le moteur Web repose sur Chromium fourni par Qt WebEngine.

Python + PySide6 + Qt WebEngine + Chromium

03. COOKIES

Le profil utilisé par OriønNull est configuré pour ne pas conserver les cookies de manière persistante.

QWebEngineProfile.NoPersistentCookies

04. CACHE

Le cache HTTP du profil est configuré en mémoire. L'objectif est d'éviter la conservation persistante du cache HTTP par le profil du navigateur.

MemoryHttpCache · Cache maximum configuré à 0

05. STOCKAGE WEB

Le stockage local du moteur WebEngine est désactivé dans la configuration du navigateur.

LocalStorageEnabled = false

06. SYNCHRONISATION

Plusieurs mécanismes Chromium associés à la synchronisation et aux communications en arrière-plan sont désactivés dans la configuration de lancement de l'application.

--disable-sync --disable-background-networking --disable-default-apps

07. TÉLÉMÉTRIE

OriønNull ne possède pas de système de télémétrie applicative volontairement intégré au projet. Certaines communications peuvent toutefois dépendre du moteur Web, du système d'exploitation ou des sites Web visités.

08. JAVASCRIPT

JavaScript reste activé afin de permettre aux sites modernes de fonctionner. Certaines capacités spécifiques sont cependant désactivées.

JavascriptEnabled = true
JavascriptCanOpenWindows = false

09. WEBGL & PLUGINS

WebGL et les plugins WebEngine sont désactivés dans la configuration actuelle afin de réduire certaines surfaces fonctionnelles inutiles au navigateur.

WebGLEnabled = false
PluginsEnabled = false

10. PERMISSIONS

Les demandes de fonctionnalités du navigateur sont refusées par défaut dans le profil utilisé par OriønNull.

PermissionDenyByUser

11. DNS & CHIFFREMENT

Le chiffrement d'une connexion HTTPS protège les données échangées entre le navigateur et le serveur lorsque le site utilise HTTPS. Cela ne signifie pas que toutes les informations réseau sont invisibles.

Important : OriønNull ne doit pas être présenté comme garantissant une anonymisation totale. HTTPS, DNS chiffré, VPN et Tor sont des mécanismes différents. Le niveau réel de confidentialité dépend également du réseau, du système et des sites visités.

12. RECHERCHE

OriønNull permet de choisir différents moteurs de recherche depuis son interface.

DuckDuckGo · Google · Brave · Bing · Ecosia · Qwant · SearXNG

13. DONNÉES LOCALES

Le navigateur cherche à réduire les données persistantes générées par son profil WebEngine. Cela ne signifie pas que le système d'exploitation, les serveurs distants ou d'autres composants du système ne peuvent jamais conserver de données.

14. CE QUE ORIØNNNULL NE PROMET PAS

  • Il ne garantit pas l'anonymat absolu.
  • Il ne rend pas une connexion Internet invisible.
  • Il ne remplace pas un VPN ou Tor.
  • Il ne peut pas contrôler les logs des sites Web visités.
  • Il ne peut pas contrôler tous les logs créés par Windows ou les logiciels tiers.

15. OBJECTIF

L'objectif d'OriønNull est de proposer un navigateur simple, rapide et orienté confidentialité, sans transformer l'interface en panneau de configuration complexe.
